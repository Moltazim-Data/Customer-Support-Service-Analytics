# Project Limitations

- All ticket, customer, and agent data is synthetic.
- SLA targets are simplified illustrative rules based on priority, not a contractual policy.
- Backlog age uses reporting cutoff 2026-01-01.
- Data is designed for portfolio analysis and is not statistically representative of a real support organization.
- DAX and build instructions are included, but no native .pbix or deployed Power BI service report is included.
- The HTML preview is a standalone demonstration, not Power BI.
